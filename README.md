# Northline News Blog

A simple, responsive news blog built with:

- HTML5
- Custom CSS
- Vanilla JavaScript
- No npm
- No packages
- No framework
- No Tailwind CSS

## Open locally

Open `index.html` directly in a modern browser.

## Edit articles

Articles live in the `articles/` folder. Copy an existing article to create a new one, then add its link and metadata to `index.html`.

## Theme

The stylesheet uses `prefers-color-scheme` so the site follows the operating system/browser light or dark preference.

## Responsive design

The layout includes desktop, tablet, and smartphone breakpoints. On small screens, the navigation becomes a working menu.

## Images

The included image areas are CSS placeholders so the project has no external image dependencies. Replace `.image-placeholder` elements with normal `<img>` elements when you add your own photography.

## Accessibility

The project includes semantic landmarks, keyboard-friendly links/buttons, accessible mobile navigation, and `prefers-reduced-motion` support.
