ABOUT NORTHLINE

A quieter way to
read the news.

Northline is a demonstration news publication built around a simple idea: good journalism does not need a complicated interface.

The design emphasizes readable typography, clear hierarchy, responsive layouts, and restrained visual effects. The project is intentionally built with plain HTML, CSS, and a small amount of vanilla JavaScript.

Built to be edited

Each article is a normal HTML file. The stylesheet is organized by layout, components, responsive behavior, and accessibility. There is no package manager or build process.
