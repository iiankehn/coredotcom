Discord’s public-server search plans put privacy controls in focus

Today’s coverage explains the opt-out ahead of November web pages and December message previews.

By Iian KehnOctober 28, 20261 min read

Windows Central’s October 28 report highlights a setting worth checking before Discord makes public communities easier to find on the web. Discord announced the change October 27; it concerns Discoverable Servers rather than private servers, direct messages, or group DMs.

Server Web Pages begin rolling out November 16. From mid-December, Discord will gradually add some public-channel messages to those pages, making that content accessible through web search. Usernames and avatars will not accompany the messages.

To exclude your message content, open User Settings, then Data and Privacy, and switch off the option labeled “Show my message content from Discoverable channels on web pages.” Administrators also have controls under Server Settings → Web Presence.

One distinction matters: the individual opt-out covers message content, while broader channel summaries have separate server-level controls. Review both if you manage a community.
