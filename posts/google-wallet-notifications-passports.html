Google Wallet adds a home for updates and more passport support

A notification feed is rolling out as additional countries appear in the ID pass setup.

By Iian KehnOctober 23, 20261 min read

Google Wallet is getting a dedicated place to catch up on changes to saved items. A bell beside the profile switcher opens the new notification feed, according to 9to5Google.

Google’s October release notes independently confirm an in-app message center. The feature is arriving through a server-side rollout, so availability can differ between accounts.

The report also identifies Estonia, Ireland, Italy, and Spain appearing in passport-based ID pass setup, with access still limited.

These are digital passes with uses that vary by country. The appearance of a passport option does not establish that every checkpoint or service will accept it. For users, the immediate changes are a clearer home for Wallet messages and a gradually expanding ID feature.
