OneDrive gets Copilot, live HTML files, and a faster sync engine

Copilot in OneDrive is now generally available, alongside HTML and Markdown collaboration, million-item sync, single sharing links, and a new Photos app for Windows.

By Iian KehnOctober 20, 20263 min read

Microsoft is repositioning OneDrive from a place where files wait to be opened into a place where Copilot works on them directly. The same update also fixes older pain points in sync, sharing, and photos.

At a OneDrive and Copilot event on October 20, Microsoft announced that Copilot is now generally available inside OneDrive and SharePoint. Rather than opening one document at a time in Word or Excel, people can select a group of files and ask Copilot to compare spreadsheets, chart trends, reorganize a cluttered project folder, or combine existing material into something new, such as an interactive HTML report.

Repeated tasks can be saved as personal skills, stored as Markdown files so Copilot runs the same steps the next time. A prompt gallery provides starting points for people who aren't sure what to ask.

HTML and Markdown become first-class files

The less flashy change may matter more. OneDrive can now open, edit, and collaborate on HTML and Markdown files, the formats AI tools increasingly produce. HTML files get a live canvas with a source view and preview side by side, full-screen presentation, and anchored comments. Markdown files get a rich-text editor that keeps the underlying .md file intact, along with real-time coauthoring and autosave.

Microsoft says the same treatment applies whether a file came from Copilot or another tool.

Sync, sharing, and admin changes

The OneDrive sync client on Windows and macOS can now handle up to one million items, and Microsoft says large libraries sync reliably on machines with as little as 8GB of RAM. Long file paths are also handled more gracefully to reduce sync errors. A new Libraries view brings SharePoint and Teams libraries into OneDrive, and libraries that people add now land in a dedicated Shortcuts folder.

Sharing is moving to what Microsoft calls Hero Links: one link per file or folder by default. Changing permissions updates who that URL works for, instead of creating another link. Organization-defined expiration policies for these links are coming later. For administrators, Microsoft also previewed folder-level sync exclusions and a command-line interface for the OneDrive sync client, which is in private preview.

Photos gets a Windows app and AI editing

On the consumer side, a new Microsoft Photos experience for Windows combines images from OneDrive, the PC, and iCloud Photos in one gallery. OneDrive is adding natural-language photo search through Copilot, curated Moments, a map view, AI editing tools for cleanup and restyling, and a Create space for collages and cards.

Not everything is shipping at once. Microsoft says some features are available now and others will roll out over the coming months. Further out, the company describes agents that can be shared on and mentioned in files, labels that identify AI-created work, and Copilot help with diagnosing broken sharing permissions.
