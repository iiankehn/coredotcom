Traycer brings 3D print progress to the Windows system tray

Released October 28, the small open-source utility keeps printer status within a glance.

By Iian KehnOctober 28, 20261 min read

Joe Finney’s Tray-tober project opened its October 28 door with Traycer, a Windows utility for keeping an eye on 3D prints from the notification area.

The application uses its tray icon to surface progress and conditions that need attention, including completed, paused, or failed jobs. Clicking opens a card for each printer, with the available detail depending on what that machine reports.

According to the project’s documentation, connections run over the local network without a cloud account. Supported integrations include Bambu Lab, PrusaLink, Klipper/Moonraker, and OctoPrint, among others. Credentials and setup requirements vary by printer.

Version 1.0.0 is listed on today’s calendar entry. The MIT-licensed project supports Windows 10 version 1809 or later and Windows 11 on x64 and ARM64.

The idea is appealingly modest: make a long-running physical job visible while you use the computer for something else.
